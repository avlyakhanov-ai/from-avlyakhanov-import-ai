# from avlyakhanov import ai

Инструкции к постам Telegram-канала `from avlyakhanov import ai`: как я применяю ИИ в работе аналитика и в обычной жизни.

Каждая папка — отдельный инструмент. Внутри `README.md` с инструкцией, которую можно целиком отдать ИИ-агенту (Claude Code, Codex): «прочитай инструкцию по ссылке и выполни ее».

| Папка | Что внутри |
|---|---|
| [typewhisper](typewhisper/) | Запись встреч с расшифровкой по ходу, конспект или разбор собеседования через Claude или Codex, скилл, чтобы просить об этом обычной фразой |
